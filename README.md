# Auxeo Codex Plugin Marketplace

This public repository distributes the thin Auxeo Agent Plugin for Codex. It contains
plugin metadata, read-only advertising Skills, public assets, and the Remote MCP address.
It does not contain the Auxeo backend, advertising credentials, tokens, or customer data.

See [INSTALL.md](INSTALL.md) for installation. Downloading the plugin grants no data
access; users must authenticate and have active Auxeo organization and resource access.
